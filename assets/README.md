# assets —— 立绘素材

**游戏默认就会用这里的图**（`js/main.js` 里 `USE_IMAGE_ASSETS` 默认 `true`）：

| 文件名 | 用途 |
|---|---|
| `fish.png` | 蓝色大肥鱼（常态） |
| `fish_bowl.png` | 蓝色大肥鱼（头顶铁盆形态） |
| `claude.png` | Claude 娘（可选，没有就用程序化画法） |
| `user.png` | 用户（可选） |

找不到文件时会静默回退到 `js/sprites.js` 的程序化画法，不会报错、不会白屏。

## 换成你自己的立绘（三种方式，任选一种）

### 方式一：拖进去（最快，零配置）

打开游戏 → 把图片**直接拖到游戏画面上**松手 → 弹出面板选「设为常态形象」或「设为铁盆形态」。
图片会存进浏览器本地存储，下次打开还在。想还原：面板右下角「恢复程序化形象」。

也可以在游戏里按 **I**，或点右上角 📖 图鉴 →「换形象素材」，从面板里选图。

### 方式二：放进这个目录

按上表的文件名丢进来，刷新页面即可。

### 方式三：关掉图片

把 `js/main.js` 里的 `var USE_IMAGE_ASSETS = true;` 改成 `false`，就完全不请求图片，
回到纯程序化画法（蓝色大肥鱼是手写的蓝发少女 + 手 K 动画）。

## 自动抠背景

图片如果是**没有透明通道的渲染图**（例如人物站在沙地上的 3D 渲染），载入时会自动处理：

1. 从四边洪水填充掉"与边缘同色"的区域（容差匹配，能吃掉渐变背景）
2. 沿颜色渐变继续向外吞掉地面阴影（每轮容差递减，遇到角色轮廓的颜色跳变就停）
3. 按行算出角色的横向剪影，清掉两侧残留的地面像素
4. 去白边、去碎屑、边缘羽化、裁到角色外框

浏览器里跑的是同一套逻辑（`js/sprites.js` 的 `processArt`）。

## 离线处理（效果更可控）

```bash
python tools/prep-art.py                      # 处理 fish.png 与 fish_bowl.png
python tools/prep-art.py 我的图.png            # 处理指定文件
```

会先把原图备份成 `*.png.bak.png`；之后**反复运行都会从备份重来**，不会二次抠图。
处理完可以直接看 `*.png` 的效果，不满意就把 `.bak.png` 改名回去。

> 只提供 `fish.png`、没给 `fish_bowl.png` 时，程序化画法会把不锈钢盆扣到你的立绘上，
> 保证「吃到铁盆大白饭后形象变化」这条玩法不会丢。
